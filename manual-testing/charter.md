# Exploratory Test Charter — Namma-Yantra Share

## Mission

Explore the farmer registration and booking flow to identify usability issues, input validation problems, unexpected behavior, and workflow defects before automation.

## Scope

* Farmer Registration
* Role Selection
* Machine Browsing
* Booking Flow
* My Bookings

## Out of Scope

* Owner-specific functionality
* Performance testing
* Security testing

## Time Box

30 minutes

## Testing Techniques

* Boundary Value Testing
* Invalid Input Testing
* Empty Field Validation
* Browser Refresh During Workflow
* Browser Back Button Navigation
* Rapid Multiple Clicks
* Long Text Input
* Special Character Input
* Invalid Phone Numbers
* Past Date Booking
* Network Interruption (if feasible)
